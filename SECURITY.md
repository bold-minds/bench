# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

To report a security issue, please use the GitHub Security Advisory ["Report a Vulnerability"](https://github.com/bold-minds/bench/security/advisories/new) tab.

We will respond within 72 hours with our evaluation and expected resolution date.

## Policy

- We will not take legal action against good-faith security researchers.
- We will handle reports with strict confidentiality.
- We will credit discoverers in public disclosures (unless you prefer otherwise).
